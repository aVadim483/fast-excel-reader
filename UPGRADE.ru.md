# Переход на 5.0

[English](UPGRADE.md)

5.0 находится в разработке. Минимальная версия PHP остаётся 7.4.

## Классы книг и расширение ридера

`Excel` теперь фасад открытия с закрытым конструктором. XLSX, XLSM, XLTX и XLTM
возвращают `avadim\FastExcelReader\Xlsx\XlsxBook`; XLS, CSV и ODS — соответственно
`XlsBook`, `CsvBook` и `OdsBook`. Универсальные фабрики возвращают `AbstractBook`.

Замените типы `Excel` и проверки `instanceof Excel` на `AbstractBook` для любого
формата либо `XlsxBook` для XML-семейства. Вместо `new Excel($file)` используйте
`Excel::openXlsx($file)` или `new XlsxBook($file)`.

Для настройки XLSX наследуйте `XlsxBook`. Публичные точки расширения `createSheet()`
и `createReader()` сохранены на этом классе; лист использует фабрику своей книги.
Универсальный `Excel::open()` не создаёт экземпляр пользовательского подкласса.
В `Excel` сохранены константы чтения, `INDEXED_COLORS`, `colNum()`, `colLetter()`
и `setTempDir()`.

## CSV

`Excel::openCsv()` теперь возвращает `CsvBook` с буквенными ключами столбцов.

```php
// Низкоуровневый код 4.x:
$reader = Excel::openCsv($file, $options);
// Замена для 5.0 с сохранением методов CsvReader и числовых ключей:
$reader = Excel::openCsvReader($file, $options);

// Общий API книги и листа:
$book = Excel::openCsv($file, $options); // openCsvBook() также сохранён
$rows = $book->sheet()->readRows();
```

Для доступа к движку открытой CSV-книги используйте `$book->getReader()`.
Явные CSV-фабрики допускают пустой файл, универсальный `open()` его отклоняет.
Опции CSV и `open($file, ['format' => 'csv'])` сохраняют своё значение.

## Определение и проверка формата

`isXlsx()` проверяет части пакета книги и поддерживаемый тип содержимого, включая
объявление типа XML по умолчанию у некоторых генераторов. Одна сигнатура ZIP больше
не даёт true. XLSM/XLTX/XLTM читает тот же ридер; VBA не выполняется. Шаблоны читаются
как сохранённое содержимое, без создания нового документа по шаблону.

`isOds()` определяет ODS по MIME-записи. Универсальные фабрики выбирают ридер
по содержимому, а не расширению. XLSB отклоняется с явным сообщением.
`validate()` проверяет обязательные части XML-книги или ODS и корректность XML,
но не схемы, вычисления формул, шифрование или полную семантику документа.
Недоступный для чтения вход вызывает исключение.

## Управление ресурсами

В долгоживущих процессах вызывайте `close()`: он закрывает собственные ридеры
и удаляет временные файлы `openString()`/`openStream()`. Повторный вызов безопасен.
Исходные файлы не удаляются; входной поток пользователя не закрывается.

```php
$book = Excel::openStream($input);
try {
    foreach ($book->sheet()->nextRow() as $row) {
        // Импорт строки.
    }
} finally {
    $book->close();
}
```

Закрытие необратимо. Новое чтение и продолжение приостановленного генератора
вызывают `The workbook is closed`. `readRows()` по-прежнему собирает весь результат
в память. Общие строки XLSX/XLS и изображения XLS также занимают память книги.
Очистка временных файлов при завершении процесса остаётся страховкой;
для своевременного освобождения не полагайтесь на момент сборки мусора.

## Отличия ODS

См. [чтение ODS](docs/ru/22-ods.md). Даты без часового пояса используют UTC,
явный сдвиг учитывается, `dateFormatter(null/false)` возвращает исходный ISO-текст.
Время и длительности сохраняются строками ISO, включая значения больше 24 часов.
Полные стили, изображения и перевод текста формул в первый ODS-ридер не входят.
