# Чтение ODS

[English](../22-ods.md) · [README](../../README.ru.md) · [Переход на 5.0](../../UPGRADE.ru.md)

```php
use avadim\FastExcelReader\Excel;

$book = Excel::openOds('data.ods'); // open(), openString(), openStream() тоже определяют ODS
try {
    foreach ($book->sheet()->nextRow() as $number => $row) {
        // Обработка строки.
    }
} finally {
    $book->close();
}
```

ODS возвращает `Ods\OdsBook` и `Ods\OdsSheet`. Общий API поддерживает выбор листа,
области, заголовки, режимы ключей, чтение строк/ячеек/столбцов и генераторы строк.
Читаются строки, числа, boolean, даты и сохранённые результаты формул.
Вычисления формул нет; текст формулы (`f`) и индекс стиля (`s`) равны null.

Даты преобразуются в Unix timestamp либо обрабатываются настроенным форматтером.
Даты без часового пояса используют UTC, явный сдвиг учитывается.
`dateFormatter(null)` или `false` возвращает исходный ISO-текст: серийного числа
Excel в ODS нет. `office:time-value` остаётся строкой ISO-длительности, например
`PT27H15M`, а не timestamp часов или `DateInterval`. Исходное значение доступно
в поле `o` при чтении с метаданными ячеек.

Поддерживаются объединения и фактические размеры. `dimension()` сначала возвращает
пустую строку, как у CSV. Методы `actualDimension()`, `dimensionArray()`, count/min/max
и `getMergedCells()` сканируют выбранную таблицу и кэшируют метаданные.
Пустые повторяющиеся строки и ячейки пропускаются с сохранением физических координат
следующих значений. Непустые повторы ограничиваются областью до разворачивания.
Первый ридер поддерживает до 1 048 576 строк и 16 384 столбцов; выход за границы
и некорректные повторы вызывают исключение.

Все листы находятся в `content.xml`: открытие перечисляет их одним потоковым проходом,
доступ к позднему листу требует пропуска предшествующего содержимого. Каждый
итератор имеет отдельный XML-курсор. В памяти находится выбранная часть строки;
полный результат `readRows()` и кэш объединений могут занимать большой объём.

Первый ридер не предоставляет стили ODS, изображения, гиперссылки, защиту,
настройки видимости и перевод OpenFormula. Общие методы стилей возвращают пустые
данные. Специфичные для XLSX методы отсутствуют на `OdsSheet`.
Зашифрованные ODS и встроенные объекты не поддерживаются. DTD отклоняется.
Неизвестный ZIP-пакет не передаётся CSV-ридеру.
